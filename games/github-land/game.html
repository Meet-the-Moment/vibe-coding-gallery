      Ride 6Fork Carousel

      You cannot push to a project you do not have permission for. A fork is your own full copy of someone else's repo, under your GitHub account. You change your fork, then send a pull request back to the original, called upstream. Press each horse in order.

      Ride 7Conflict Funhouse

      When two branches change the same lines of the same file, Git cannot guess which is right. It stops, marks both versions in the file and asks a human. That is a merge conflict. They look scary but are simple to fix.

      Your branch says

      <h1>Donate today</h1>

      main says (Sam changed it)

      <h1>Support our mission</h1>

      index.html after git merge main

      The red markers show the clash. Everything between <<<<<<< and ======= is yours. Everything after it is theirs. Pick a resolution.
